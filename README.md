# مقارنة ملفات Excel حسب الرقم الوظيفي

تطبيق HTML واحد (بدون خادم) لمقارنة ملفي Excel — مثل **الحسابات** مع **البصمة** أو **الإدارة** مع **البصمة** — عن طريق الرقم الوظيفي.

## طريقة الاستخدام
1. افتح `excel-compare.html` (ملف واحد يعمل بدون إنترنت)، أو `index.html` مع مجلد `lib` بجانبه. بعد تعديل `index.html` شغّل `python3 build-standalone.py` لتحديث النسخة الموحدة.
2. اكتب اسم الملف الأول ثم اضغط **استيراد ملف Excel** (أعمدة: `ID` / `Name` أو `الرقم الوظيفي` / `الاسم`).
3. كرر نفس الخطوات للملف الثاني.
4. اضغط **قارن**.

يتم التعرف على صف العناوين والأعمدة تلقائياً، ويمكن تغيير الورقة أو الأعمدة يدوياً من القوائم.

## التقارير
| التقرير | المعنى |
|---|---|
| متطابق تماماً | نفس الرقم الوظيفي ونفس الاسم |
| اختلاف في الاسم | نفس الرقم الوظيفي والاسم مختلف (مع نسبة التشابه وتظليل الكلمات المختلفة) |
| موجود في الملف الأول فقط | غير موجود في الملف الثاني |
| موجود في الملف الثاني فقط | غير موجود في الملف الأول |
| أرقام مكررة | نفس الرقم مكرر داخل نفس الملف (للعلم؛ كل الصفوف تدخل المقارنة) |

## المطابقة اليدوية والنقل بين التقارير
- **🔗 المطابقة اليدوية (الباقي من الملفين):** الباقي من كل ملف بعد المتطابق التام والجزئي يظهر في قائمتين جنب بعض. اختر اسماً من كل جهة ثم **ربط كمطابق تام** أو **ربط كمطابق جزئي**. عند اختيار اسم تُرتَّب القائمة الأخرى حسب نسبة التشابه.
- **✔ نقل إلى تام:** من تقرير الاختلاف في الاسم بعد التأكد.
- **⇠ جزئي / ✂ فك الربط:** لإرجاع أي مطابقة خاطئة.
- **✖ غير موجود فعلاً:** يُنقل إلى تقرير «مؤكد غير موجود» (ويمكن إرجاعه).
- شريط **نسبة الإنجاز** يوضح المتبقي حتى تكتمل المقارنة.
- كل عملية نقل تطلب تأكيداً قبل التنفيذ، ويتم حفظها ضمن ملف JSON.

## الطباعة والتصدير
- **طباعة** أي تقرير منفرد أو كل التقارير.
- **تصدير** إلى Excel (كل تقرير في ورقة مستقلة).
- **حفظ / فتح JSON** لحفظ البيانات والنتائج وإعادة فتحها لاحقاً.

## خيارات المقارنة
- توحيد الحروف العربية (أ إ آ ← ا، ة ← ه، ى ← ي) وإزالة التشكيل.
- تجاهل المسافات الزائدة وحالة الأحرف الإنجليزية.
- تجاهل الأصفار في بداية الرقم الوظيفي (اختياري).
- الرقم الفارغ أو NULL أو N/A أو - أو 0 يُعتبر «بدون رقم»، وتُطابق هذه الصفوف بالاسم تلقائياً إذا كان الاسم فريداً، والباقي يظهر في المطابقة اليدوية.

جميع البيانات تُعالج داخل المتصفح فقط. مكتبة قراءة Excel: [SheetJS](https://sheetjs.com) (`lib/xlsx.full.min.js`، رخصة Apache 2.0).
