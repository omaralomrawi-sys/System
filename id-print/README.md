# ID Print – طباعة المستمسكات

تطبيق HTML واحد يعمل بدون إنترنت: افتح `id-print.html` في المتصفح.

- اسحب صور/PDF إلى الإطارات (أو الصق بـ Ctrl+V)، وكل إطار بقياسه الحقيقي بالمليمتر.
- قوالب: بطاقة وطنية (وجه/ظهر)، سكن، جواز، A4/A5/A6، صور… + قياسات مخصصة تُحفظ.
- قص/تدوير/سطوع/تباين/أبيض وأسود/تحسين تلقائي، سماكة الحد، ترتيب تلقائي، التصاق.
- حفظ اللاي اوت في المتصفح أو كملف JSON (مع/بدون الصور).
- تصدير PDF وطباعة، وصفحة ظهر مرآتية للطباعة على الوجهين.
- متصفح ملفات الحاسبة (Chrome/Edge): افتح مجلداً لتظهر الصور وPDF كمصغّرات واسحبها للصفحة.
- زر الفأرة الأيمن على الصفحة: إضافة مستمسك (وجه + ظهر). الإطارات الفارغة لا تُطبع.
- وضع داكن/فاتح، وتثبيت واجهة افتراضية.
- عند الطباعة اختر: Margins = None و Scale = 100%.

التطوير: عدّل `index.html` ثم شغّل `python3 build-standalone.py` لتحديث `id-print.html`.

## نسخة سطح المكتب (Windows .exe) – وصول كامل لملفات الحاسبة
مجلد `id-print/desktop` يغلّف التطبيق بـ Electron فيفتح سطح المكتب والمستندات والتنزيلات والأقراص مباشرة بدون أي إذن.
- **ملف exe جاهز:** GitHub → تبويب Actions → «Build ID Print (Windows exe)» → افتح آخر تشغيل → Artifacts → `ID-Print-windows` (يُبنى تلقائياً عند أي تعديل في `id-print/`).
- **أو محلياً (يتطلب Node.js):** شغّل `id-print/desktop/start-windows.bat`.
