# ID Print – طباعة المستمسكات

تطبيق HTML واحد يعمل بدون إنترنت: افتح `id-print.html` في المتصفح.

- اسحب صور/PDF إلى الإطارات (أو الصق بـ Ctrl+V)، وكل إطار بقياسه الحقيقي بالمليمتر.
- قوالب: بطاقة وطنية (وجه/ظهر)، سكن، جواز، A4/A5/A6، صور… + قياسات مخصصة تُحفظ.
- قص/تدوير/سطوع/تباين/أبيض وأسود/تحسين تلقائي، سماكة الحد، ترتيب تلقائي، التصاق.
- حفظ اللاي اوت في المتصفح أو كملف JSON (مع/بدون الصور).
- تصدير PDF وطباعة، وصفحة ظهر مرآتية للطباعة على الوجهين.
- عند الطباعة اختر: Margins = None و Scale = 100%.

التطوير: عدّل `index.html` ثم شغّل `python3 build-standalone.py` لتحديث `id-print.html`.
